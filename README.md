项目名称：基于K模自然向量的病原体基因组系统发育分析和传播动态研究

本数据集收录了博士毕业论文《基于K模自然向量的病原体基因组系统发育分析和传播动态研究》中使用的所有核心实验数据。数据涵盖病毒与细菌两大类的基因组序列、突变特征、元数据以及基于K模自然向量（K-mer Natural Vector,KNV）方法的基因分型与传播推断结果。

基因组数据集信息（数据集.xlsx）和SARS-CoV-2基因组突变信息（突变信息.xlsx）

# 本论文第3章 病毒基因组的系统发育分析和传播动态研究
1 SARS-CoV-2基因组数据集
本研究从公共数据库GISAID中收集了三组SARS-CoV-2基因组数据, 用于阐明新型网络表示方法在SARS-CoV-2的系统发育分析和传播动态研究中的有效性. SARS-CoV-2基因组序列的基本信息见数据集.xlsx文件中S1-S3, 包含SARS-CoV-2基因组序列在GISAID中的登录号、基因组标识符、采样地理位置和样本采集日期. 
数据集S1: 158个SARS-CoV-2基因组用于了解病毒基因组的进化选择, 并模拟其在人群中的传播趋势. 
数据集S2: 247个SARS-CoV-2基因组的系统发育网络用于识别超级传播者并追踪传播路径. 
数据集S3: 184个SARS-CoV-2基因组（包括片段缺失、模糊碱基或测序错误的基因组）用于确定亲本菌株, 并利用这些菌株检测疫苗的有效性. 

2. SARS-CoV-2基因组突变信息
SARS-CoV-2基因组突变信息保存在突变信息.xlsx文件中, 其中记录了158个SARS-CoV-2基因组（G1-G4组）和247个SARS-CoV-2基因组（C1-C5组）相对于参考毒株Wuhan/Hu-1的突变分布情况. 该文件包含参考毒株名称、突变在基因组上的具体位置、突变在群体中的分布情况、突变频率和特征/标记突变位点. 
•字段说明：
◦Reference strain：参考毒株名称。
◦Position：突变在基因组上的具体位置。
◦Mutation distribution：突变在群体中的分布情况。
◦Mutation frequency：突变频率。
◦Signature mutation：特征/标记突变位点（用于区分不同分组）。

# 本论文第4章 细菌基因组的群体结构解析和基因分型
屎肠球菌、炭疽芽孢杆菌和脓肿分枝杆菌基因组数据集
本研究从NCBI和EBI数据库中收集了三组具有不同遗传特征的细菌基因组数据集, 以评估cgKNV在细菌群体结构分析和基因分型中的性能表现. 细菌基因组数据集的基因组序列信息见数据集.xlsx文件中S4-S6, 包含屎肠球菌、炭疽芽孢杆菌和脓肿分枝杆菌的基因组序列在NCBI或EBI中的登录号及利用cgKNV、wgSNP、cgSNP和cgMLST方法得到的聚类结果. 
数据集S4: 346个屎肠球菌分离株用于推断屎肠球菌的群体结构, 其中参考基因组NC_017022.1包含3118个基因, 筛选其中的1423个保守基因作为核心基因组. 
数据集S5: 来自全球六大洲50个国家的583个炭疽芽孢杆菌基因组用于基因组分型和关联关系推断. Ames Ancestor 菌株NC_007530.2作为参考基因组, 从5234个基因中筛选出3803个基因作为核心基因组. 
数据集S6: 1786株脓肿分枝杆菌基因组, 全面覆盖该菌种所有亚种的遗传多样性特征. Mab-A型菌株ATCC19977（NC_010397.1）作为参考基因组, 从4960个基因中定义了2904个核心基因. 

# 本论文第5章 结核分枝杆菌复合群基因组的菌株分型和传播路径推断
MTBC基因组数据集
本研究从NCBI和EBI数据库中收集了三组MTBC基因组数据集, 以验证MTBC代表性基因组筛选模型的有效性及cgKNV在MTBC的系统发育分析和传播动态研究中的实用性. 三组MTBC基因组的基本序列信息见数据集.xlsx文件中S7-S9. 该文件包含MTBC菌株编号、分离株登录号、代表性分离株登录号、谱系及分组信息、11个聚类群组成员及对应的患者ID、cgKNV分型结果、Coll等人(2014)的分型结果和MIRU-VNTR基因分型结果等. 
数据集S7: 296株MTBC菌株的382个完整基因组, 用于MTBC全球群体结构分析. 该菌株集合涵盖了所有MTBC谱系. 
数据集S8: 德国汉堡纵向流行病学监测队列（始于1997年1月）中的52名患者的92株MTBC分离株, 用于解析菌株群体结构特征和推断传播路径. 这些菌株来自于七个由IS6110界定的聚类群. 
数据集S9: 对来自英国中部地区的11个社区聚类的217株MTBC菌株进行了基因型鉴定和传播路径推断. 这些基于MIRU-VNTR确定的社区聚类（包含6至47名患者）既包括了接触者追踪数据支持的传播病例, 也包括传播关系尚不确定的病例. 

•关键字段说明：
字段名	说明
Strain ID / Isolate ID	菌株编号及分离株登录号
Isolate chosen with simulated annealing	通过模拟退火算法筛选的分离株ID
Lineage / Group	谱系及分组信息
Genotyping with cgKNV	本研究方法：基于核心基因组K模自然向量的基因分型结果
Genotyping by Coll 2014	对照方法：Coll等人(2014)的分型结果
mean coverage depth	平均测序深度
coverage breadth	覆盖度（分数）
Clusters / Patient Id	聚类群组成员及对应的患者ID（用于传播链推断）
MTB lineages inferred with cgKNV	基于cgKNV推断的MTB（结核分枝杆菌）谱系
MIRU-VNTR types  对照方法：MIRU-VNTR 基因分型结果
