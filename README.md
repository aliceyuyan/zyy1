项目名称：基于K模自然向量的系统发生分析和传播动态研究

本数据集收录了博士毕业论文《基于K模自然向量的系统发生分析和传播动态研究》中使用的所有核心实验数据。数据涵盖病毒与细菌两大类的基因组序列、突变特征、元数据以及基于K模自然向量（K-mer Natural Vector,KNV）方法的基因分型与传播推断结果。

# 本论文第3章 病毒基因组的系统发生分析和传播动态研究
本章包含病毒基因组数据集1-3.xlsx和病毒基因组G1-G4,C1-C5的突变信息.xlsx两个文件。

1. 病毒基因组元数据
•文件名：病毒基因组数据集1-3.xlsx
•描述：包含新冠病毒基因组序列的基础信息与基因组标识符，用于构建新冠病毒基因组的系统发生网路，研究新冠病毒在人群中的传播趋势。
•字段说明：
字段名	说明
Accession_ID	序列在公共数据库（如GISAID）的登录号
Genome ID	内部使用的基因组唯一标识符
Location	采样地理位置
Collection_date	样本采集日期
2. 病毒突变特征分析
•文件名：新冠病毒基因组G1-G4,C1-C5的突变信息.xlsx
•描述：记录了新冠病毒不同分组（G1-G4, C1-C5）相对于参考株Wuhan/Hu-1的突变分布情况，用于了解新冠病毒基因组的进化选择。
•字段说明：
◦Reference strain：参考毒株名称。
◦Position：突变在基因组上的具体位置。
◦Mutation distribution：突变在群体中的分布情况。
◦Mutation frequency：突变频率。
◦Signature mutation：特征/标记突变位点（用于区分不同分组）。

# 本论文第4章 细菌基因组的系统发生分析
本章包含一个文件：细菌基因组数据集S1-S3.xlsx。
•文件名：细菌基因组数据集S1-S3.xlsx
•描述：包含肠球菌、炭疽芽孢杆菌和脓肿分枝杆菌的元数据及分析结果。
•内容：涵盖上述三种细菌的基因组序列信息及基于cgKNV（核心基因组K模自然向量）、wgSNP（全基因组单核苷酸多态性）和cgMLST（核心基因组多位点序列分型）等方法的系统发生分析结果，用于细菌的系统发生树构建验证。

# 本论文第5章 结核分枝杆菌复合群基因组的系统发生分析和传播动态研究
本章包含一个文件：结核分枝杆菌复合群基因组数据集T1-T3.xlsx。
•文件名：结核分枝杆菌复合群基因组数据集T1-T3.xlsx
•描述：包含结核分枝杆菌复合群基因组的元数据、基于模拟退火算法筛选的分离株及cgKNV分型结果。
•关键字段说明：
字段名	说明
Strain ID / Isolate ID	菌株编号及分离株登录号
Isolate chosen with simulated annealing	通过模拟退火算法筛选的分离株ID
Lineage / Group	谱系及分组信息
Genotyping with cgKNV	本研究方法：基于核心基因组K模自然向量的基因分型结果
Genotyping by Coll 2014	对照方法：Coll等人(2014)的分型结果
mean coverage depth	平均测序深度
coverage breadth	覆盖度（分数）
Clusters / Patient Id	聚类群组成员及对应的患者ID（用于传播链推断）
MTB lineages inferred with cgKNV	基于cgKNV推断的MTB（结核分枝杆菌）谱系
MIRU-VNTR types  对照方法：MIRU-VNTR 基因分型结果

# 数据使用说明
•病毒基因组数据集1-3.xlsx和病毒基因组G1-G4,C1-C5的突变信息.xlsx两个文件可用于病毒的系统发生分析和传播动态研究。
•细菌基因组数据集S1-S3.xlsx和结核分枝杆菌复合群基因组数据集T1-T3.xlsx两个文件可用于细菌的系统发生分析和传播动态研究。
