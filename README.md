项目名称：基于K模自然向量的系统发生分析和传播动态研究
更新日期：2026年5月

本数据集收录了博士毕业论文《基于K模自然向量的系统发生分析和传播动态研究》中使用的所有核心实验数据。数据涵盖病毒与细菌两大类的基因组序列、突变特征、元数据以及基于K模自然向量（Natural Vector）方法的基因分型与传播推断结果。

# 3 病毒基因组的系统发生分析和传播动态研究,
包含两个文件：病毒基因组数据集1-3.xlsx和病毒基因组G1-G4,C1-C5的突变信息.xlsx

# 病毒基因组元数据
•文件名：病毒基因组数据集1-3.xlsx
•描述：包含病毒样本的基础采样信息与基因组标识符，用于构建时空传播模型。
•字段说明：
字段名	说明
Accession_ID	序列在公共数据库（如NCBI）的登录号
Genome ID	内部使用的基因组唯一标识符
Location	采样地理位置
Collection_date	样本采集日期
# 病毒突变特征分析
•文件名：病毒基因组G1-G4,C1-C5的突变信息.xlsx
•描述：记录了病毒不同分组（G1-G4, C1-C5）相对于参考株的突变分布情况，用于计算自然向量及特征提取。
•字段说明：
◦Reference strain：参考毒株名称。
◦Position：突变在基因组上的具体位置。
◦Mutation distribution：突变在群体中的分布情况。
◦Mutation frequency：突变频率。
◦Signature mutation：特征性/标志性突变位点（用于区分不同谱系）。
# 4 细菌基因组的系统发生分析
•文件名：细菌基因组数据集S1-S3.xlsx
•描述：包含肠球菌、炭疽杆菌和脓肿分枝杆菌的元数据及分析结果。
•内容：涵盖上述三种细菌的基因组序列信息及基于K模自然向量的初步分析指标，用于跨物种的系统发生树构建验证。
# 5 结核分枝杆菌复合群基因组的系统发生分析和传播动态研究
•文件名：结核分枝杆菌复合群基因组数据集T1-T3.xlsx
•描述：针对结核分枝杆菌复合群的高分辨率数据集，包含基于模拟退火算法筛选的分离株及cgKNV（核心基因组K模自然向量）分型结果。
•关键字段说明：
字段名	说明
Strain ID / Isolate ID	菌株编号及分离株登录号
Isolate chosen with simulated annealing	是否通过模拟退火算法筛选
Lineage / Group	谱系及分组信息
Genotyping with cgKNV	本研究方法：基于核心基因组K模自然向量的基因分型结果
Genotyping by Coll 2014	对照方法：Coll等人(2014)的分型结果
mean coverage depth	平均测序深度
coverage breadth	覆盖度（分数）
Clusters / Patient Id	聚类群组成员及对应的患者ID（用于传播链推断）
MTB lineages inferred with cgKNV	基于cgKNV推断的MTB谱系
